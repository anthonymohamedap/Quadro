# Mock verkoopdossier (US-87 → US-95)

HTML-mock, geen app-code. Open de bestanden in een browser (dubbelklik); het scherm kies je met `?s=…`
achter de bestandsnaam.

| Bestand | Schermen (`?s=`) |
|---|---|
| `dossier.html` | eerste schets (lijst Verkopen, stap 3, 5, afgerond) — wordt herzien met de grondregel bij stap 3–5 |
| `stap1.html` | `nieuw` · `leeg` · `maat` · `lijstkiezen` · `kader` · `fouten` · `voorschot` · `afdrukken` · `bevestigen` · `menu` · `annuleren` · `geannuleerd` |
| `logica.html` | logica van stap 1: verloop, controles, bevestigen, prijsberekening (ongewijzigd), annuleren, beslissingen |
| `stap2.html` | `hoofd` · `inplannen` · `bestellen` · `gepland` · `start` · `afdrukken` · `overslaan` · `annuleren` · `terugkijken` |
| `logica2.html` | logica van stap 2: inplannen, voorraad en lijsten bestellen, start productie, overslaan, annuleren, afdrukken, open vragen |
