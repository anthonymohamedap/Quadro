# Mock verkoopdossier (US-87 → US-95)

HTML-mock, geen app-code. **Elk bestand staat op zichzelf** (stijl, script en logo zitten erin).

**Openen:** dubbelklik het bestand in je lokale kopie van de repo (branch `dev`), of download het bestand
van GitHub (knop "Download raw file") en dubbelklik het. In het GitHub-venster zelf zie je enkel de code:
GitHub voert geen pagina's uit.

Linksonder staat een zwarte knoppenbalk **"MOCK — kies een scherm"** om tussen de schermen te wisselen.

| Bestand | Inhoud |
|---|---|
| `stap1.html` | stap 1 Offerte: alle velden van het huidige offertescherm (nieuw, leeg, maat, lijst kiezen, kader, fouten, voorschot, afdrukken, bevestigen, menu, annuleren, geannuleerd) |
| `logica.html` | logica van stap 1 |
| `stap2.html` | stap 2 Werkbon (hoofd, inplannen, bestellen, gepland, start, afdrukken, overslaan, annuleren, terugkijken) |
| `logica2.html` | logica van stap 2 |
| `dossier.html` | eerste schets (lijst Verkopen, stap 3, 5, afgerond) — wordt herzien met de grondregel bij stap 3–5 |

Testgegevens: verkoop 423, Sofie Claes, € 245 met € 100 voorschot. Beslissingen: zie
